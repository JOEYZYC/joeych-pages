# Jekyll Source Archive

`Jeklly/` is a non-runnable, non-deployed source archive. GitHub Pages is disabled, and this directory has no deployment, compilation, testing, or runtime support.

Retained archive groups are:

- Route, redirect, feed, and historical post files.
- Liquid includes and layouts.
- Jekyll configuration and the design contract.
- CSS and JavaScript source under `assets/`.

Shared public [page and project bundles](../Profile/) are owned by `Profile/`. Local archive material and generated mirrors remain ignored under the workspace firewall.
